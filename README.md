# 한 문제씩

직업상담사 2급 실기 문제를 한 문제씩 연습하는 설치형 웹앱입니다.

계정은 앱 관리자에게 안내받아 사용합니다. 로그인하지 않으면 브라우저 전용 저장으로 작동합니다.

- 12개 강의에서 정리한 137문항. 계산 문항은 제외하고, 불명확한 27항목(사례 변형 포함)은 보류했습니다.
- 내 답안, 세 단계 기억 표시, 기억 정도별 복습. 전체 또는 여러 강의와 기억 정도를 함께 선택하고 순서대로·랜덤으로 풀 수 있습니다. 복습 중 기억 정도를 바꿔도 이번 문제 목록과 순서는 유지됩니다.
- 연습 답안은 현재 문제에서만 유지됩니다. 문제를 이동하거나 앱을 다시 열면 빈칸으로 시작하며, 브라우저·계정에 저장하지 않습니다. 과거에 저장한 연습 답안도 불러오거나 계정으로 가져오지 않습니다.
- 모범답안은 문제를 열 때마다 접힌 상태로 시작합니다.
- 기억 정도, 수정한 모범답안 및 암기 팁은 계속 저장하며 원본 확인과 복원이 가능합니다.
- Supabase에 로그인하면 같은 계정으로 휴대폰과 PC의 기록을 공유합니다.
- 기록은 기기에 먼저 저장합니다. 오프라인 기록은 연결되면 다시 동기화됩니다. 같은 문항의 같은 항목을 두 기기에서 수정하면 마지막으로 서버에 저장한 내용이 적용됩니다.
- 로그인 없이 작성한 기록은 계정 화면에서 명시적으로 가져올 수 있습니다. 기존 계정 기록을 덮어쓰지 않습니다.

2026-10-05 제공 교재 사진을 대조해 1강에 게슈탈트 상담기법 3가지와 REBT의 ABCDEF 의미를 추가했습니다. ABCDE 사례 변형은 전체 답안 확인 전까지 보류합니다.

## 개발 및 배포

`dist/`가 배포되는 앱 파일이며, `src/cloud.js`와 `src/account-store.js`는 로그인·동기화 구현입니다. GitHub Pages는 `main`의 `dist/`를 배포합니다. 콘텐츠 원본 자막과 로컬 검토 자료는 공개 저장소에 포함하지 않습니다.

Node 22 이상, pnpm 11에서 `pnpm install --frozen-lockfile`, `pnpm test`, `pnpm build`를 실행합니다. 빌드한 `dist/`를 커밋하고 푸시하면 배포됩니다. 빌드 시 앱 파일의 해시로 오프라인 캐시 버전을 갱신합니다.

`dist/config.json`에는 Supabase URL과 공개용 publishable key만 들어갑니다. 관리자 키는 포함하지 않습니다. `supabase/schema.sql`은 로그인 사용자가 자신의 기록만 읽고 수정하도록 RLS를 적용합니다. 앱의 학습 기록은 공개 저장소에 저장하지 않습니다.

기존 브라우저 전용 기록은 그 브라우저의 해당 주소에 남습니다. 호스팅 주소가 달라지면 브라우저 저장 공간도 달라집니다.
